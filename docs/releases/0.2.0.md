# RuField 0.2.0

Release candidate for all ten workspace crates.

## Changes

- Bounded W1700K JSONL quality adapter and replay CLI.
- Advisory baseline analysis with abstention on continuity faults.
- RF evidence excluded from occupancy fusion.
- Animated SVG with reduced motion support bundled in every crate.

## End to end use

Build the W1700K producer from RuView PR 2267. Pipe producer JSONL into `rf-diagnostics-replay` for field evidence or `rf-diagnostics-analyze` for baseline reports. The analyzer consumes diagnostics, not replay output.

Configuration remains unverified. Reports have zero confidence and unknown cause. Synthetic fixtures validate software behavior only; live hardware validation is outstanding. There is no automatic retuning, suppression or presence inference.

## Publication

Run workspace tests, the SVG verifier and cargo package --workspace on the release commit. Configure CARGO_REGISTRY_TOKEN before the manual Release workflow. Verify all ten registry versions before announcing availability.

The SVG is bundled at assets/rufield-rf-observatory.svg in each crate.

## Baseline limits

Sixteen 2048-sample slices cover only 0.8192 ms at 40 Msps or 0.1024 ms at 320 Msps. The 6 dB threshold is a diagnostic heuristic, not validated interference detection. Gain changes and signal scaling may explain a rise.
