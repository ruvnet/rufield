# rufield-viewer 0.2.0

RuField MFS read-only web dashboard: drives the SyntheticSim → fusion pipeline and streams live camera-free room intelligence (ADR-260 §14 Layer 7 / §27.9).

![RuField RF observatory: unverified diagnostics remain advisory](https://raw.githubusercontent.com/ruvnet/rufield/main/docs/assets/rufield-rf-observatory.svg)

```sh
cargo add rufield-viewer@0.2.0
```

RF diagnostics do not establish interference causality, occupancy or physical sensing accuracy. Synthetic tests validate software behavior only.
